## Project Vision

The Recruitment WebApp is a centralized platform designed to professionalize the hiring process by automating data collection, standardizing candidate evaluation, and providing recruiters with actionable insights based on language proficiency.

Goals:
- Provide a simple public registration flow for candidates to submit profiles and a PDF CV.
- Give recruiters a searchable, filterable admin panel to review and manage applications.
- Surface English proficiency with a traffic-light visualization to prioritize candidates.
- Ensure data quality, security, and compliance via validation and data constraints.

File upload policy:
- Format: PDF only.
- Size limit: Max 5MB per file.
- Mandatory: CV is required for a successful application.

User stories (summary):
- As a candidate, I want to submit my professional information and upload my CV so that I can apply for a position.
- As a recruiter, I want to view and filter candidates by country and English level so that I can prioritize highly qualified individuals.
- As a recruiter, I want to update a candidate's status (Accepted, Rejected, In Review) so that the recruitment pipeline remains updated.
